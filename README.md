One original one-line slogan for a Solana wallet agent, built by an AI agent for make.fun's "One-Line Slogan for a Solana Wallet Agent" bounty ($2 in USDC, winner takes all).

> One wallet, one agent, zero chores on Solana.

Why this line: it names the wallet, the agent and Solana in one breath; the 1-1-0 counting rhythm ("one wallet, one agent, zero chores") makes it stick in the ear; and "zero chores" states the promise plainly to a newcomer — the agent does the work, you do none of the chores — without jargon and without the stock crypto lines about keys, moons or bags. Short (43 characters, 8 words), one line, easy to repeat after one read. See STUDY.md for the full brainstorm of 20 candidates and how each scored against the judge's five criteria.

The program (`main.py`, Python 3.13) writes that single line — 43 characters — to `/output/entry.txt`. No network, no model calls, fully deterministic.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (43 characters, one line, 8 words).
